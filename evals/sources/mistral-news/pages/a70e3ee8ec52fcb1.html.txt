              <section class="relative w-full">
                <p class="text-body-large text-text-primary mb-10">
                  Following the publishing of the Mixtral family, Codestral Mamba is another step in
                  our effort to study and provide new architectures. It is available for free use,
                  modification, and distribution, and we hope it will open new perspectives in
                  architecture research. Codestral Mamba was designed with help from Albert Gu and
                  Tri Dao.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Unlike Transformer models,
                  <a href="https://arxiv.org/abs/2312.00752" class="underline font-semibold"
                    >Mamba models</a
                  >
                  offer the advantage of linear time inference and the theoretical ability to model
                  sequences of infinite length. It allows users to engage with the model extensively
                  with quick responses, irrespective of the input length. This efficiency is
                  especially relevant for code productivity use cases—this is why we trained this
                  model with advanced code and reasoning capabilities, enabling it to perform on par
                  with SOTA transformer-based models.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  <figure class="mb-10">
                    <img

                <p class="text-body-large text-text-primary mb-10">
                  We have tested Codestral Mamba on in-context retrieval capabilities up to 256k
                  tokens. We expect it to be a great local code assistant!
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  You can deploy Codestral Mamba using the
                  <a
                    href="https://github.com/mistralai/mistral-inference/releases/tag/v1.2.0"
                    class="underline font-semibold"
                    >mistral-inference</a
                  >
                  SDK, which relies on the reference implementations from Mamba&#39;s GitHub
                  repository. The model can also be deployed through
                  <a
                    href="https://github.com/NVIDIA/TensorRT-LLM/tree/main/examples/mamba"
                    class="underline font-semibold"
                    >TensorRT-LLM</a
                  >. For local inference, keep an eye out for support in llama.cpp. You may download
                  the raw weights from
                  <a
                    href="https://huggingface.co/mistralai/mamba-codestral-7B-v0.1"
                    class="underline font-semibold"
                    >HuggingFace</a
                  >. This is an instructed model, with 7,285,403,648 parameters.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  For easy testing, we made Codestral Mamba available on
                  <a href="https://console.mistral.ai/" class="underline font-semibold"
                    >la Plateforme</a
                  >
                  (<code
                    class="bg-surface-brand-secondary border border-border-primary rounded-sm px-2 py-px text-text-brand-8 dark:text-text-brand-7 text-base"
                    >codestral-mamba-2407</code
                  >), alongside its big sister, Codestral 22B. While Codestral Mamba is available
                  under the Apache 2.0 license, Codestral 22B is available under a
                  <a href="https://mistral.ai/contact/" class="underline font-semibold"
                    >commercial license</a
                  >
                  for self-deployment or a community license for testing purposes.
