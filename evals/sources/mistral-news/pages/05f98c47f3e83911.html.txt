                <p class="text-body-large text-text-primary mb-10">
                  Mixtral 8x22B is our latest open model. It sets a new standard for performance and
                  efficiency within the AI community. It is a sparse Mixture-of-Experts (SMoE) model
                  that uses only 39B active parameters out of 141B, offering unparalleled cost
                  efficiency for its size.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Mixtral 8x22B comes with the following strengths:
                </p>
                <ul class="mb-10 pl-5 flex flex-col gap-2 list-disc">
                  <li>
                    <p class="text-body-large text-current">
                      It is <strong>fluent in English, French, Italian, German, and Spanish</strong>
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      It has strong mathematics and coding capabilities
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      <strong>It is natively capable of function calling</strong>; along with the
                      constrained output mode implemented on la Plateforme, this enables application
                      development and tech stack modernisation at scale
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Its <strong>64K tokens context window</strong> allows precise information
                      recall from large documents
                    </p>
                  </li>
                </ul>

                  and collaboration in AI.
                </p>

                  open-source licence, allowing anyone to use the model anywhere without
                  restrictions.

                </p>

                  capable than any other open-weight model (distributed under permissive or
                  restrictive licenses). The base model&#39;s availability makes it an excellent
                  basis for fine-tuning use cases.
