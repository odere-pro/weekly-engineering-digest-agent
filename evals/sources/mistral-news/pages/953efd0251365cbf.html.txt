              <section class="relative w-full">
                <p class="text-body-large text-text-primary mb-10">
                  As conversational AIs get more capable, our expectations grow with them. We don’t
                  just want faster answers, we want tools that remember, adapt, and fit the way we
                  work. That’s where
                  <a
                    href="https://chat.mistral.ai/memories"
                    target="_blank"
                    rel="noopener noreferrer"
                    class="underline font-semibold"
                    >Memories (beta)</a
                  >
                  come in. And with it, new questions: What should an AI remember? How should it
                  recall? And what does it take for you to trust it?
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  What users told us.
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  When we talked to users across personal and professional settings, three
                  consistent needs stood out: transparency, control, and focus. People want the
                  ability to ask, “What do you know about me?” and get a clear answer. They also
                  want memory to stay on-task. As one Le Chat user put it: “I need a hammer, not a
                  friend.”
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  For some, that means citations: show me exactly which conversation or file a
                  response is pulling from. For others, it means scoped recall, project-specific
                  details, not casual asides from months ago. Whatever the preference, one thing is
                  clear: memory should stay visible, editable, and under your control.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  A memory system built for users.
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Many AI tools today store information automatically. Some resurface it without
                  warning; others only recall when you explicitly ask.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Le Chat takes a hybrid approach. It saves useful information automatically, like
                  jotting down a note while you talk. But recall is designed to be smart, timely,
                  and visible. You’ll always see what memory is in play, with links to the source.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  That design comes from a simple philosophy: An AI assistant should help you think
                  better, not guess what it’s doing. Here’s how we put that into practice.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Three principles behind Le Chat’s memory.
                </h2>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  Transparency.
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  You’ll always know when memory is being used. Le Chat clearly shows when it’s
                  recalling something, where it came from, and why it’s relevant. Think of it like
                  clickable receipts.
                </p>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">Agency.</h3>
                <p class="text-body-large text-text-primary mb-10">
                  Memory is something you manage—not something that manages you.<br />You can:
                </p>
                <ul class="mb-10 pl-5 flex flex-col gap-2 list-disc">
                  <li><p class="text-body-large text-current">Turn Memories off anytime</p></li>
                  <li>
                    <p class="text-body-large text-current">
                      Start an incognito chat that doesn’t use memory
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Edit or delete individual memories from your log
                    </p>
                  </li>
                </ul>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">Sovereignty.</h3>
                <p class="text-body-large text-text-primary mb-10">
                  You own your memories. Export them. Import from elsewhere. Memories in Le Chat are
                  portable and interoperable by design, because control shouldn’t stop at the
                  interface.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  What it helps you do.
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Memory makes your assistant more useful over time, without getting in the way.
                  That can look like:
                </p>
                <ul class="mb-10 pl-5 flex flex-col gap-2 list-disc">
                  <li>
                    <p class="text-body-large text-current">
                      Recalling how you solved a similar problem last quarter
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Surfacing a past insight you’d forgotten
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Connecting your current query to something you said in another thread
                    </p>
                  </li>
                </ul>
                <section class="mb-10">

                <p class="text-body-large text-text-primary mb-10">
                  One user asked a follow-up about a legal policy weeks after uploading a PDF. Le
                  Chat instantly found the right section in the document, without needing to
                  re-upload or re-explain. That kind of connective recall saves time and unlocks
                  flow. No retraining. No do-overs.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Try it now: Memory Insights.
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  We introduced
                  <a
                    href="https://chat.mistral.ai/memories"
                    target="_blank"
                    rel="noopener noreferrer"
                    class="underline font-semibold"
                    >Memory Insights</a
                  >, lightweight prompts that help you explore what Le Chat remembers and how it can
                  help. They surface trends, suggest summaries, and point out moments worth
                  revisiting, all based on your own data, and all editable. It’s a simple way to
                  turn memory from passive storage into active signal. Download Le Chat on the
                  <a
                    href="https://apps.apple.com/fr/app/le-chat-by-mistral-ai/id6740410176"
                    target="_blank"
                    rel="noopener noreferrer"
                    class="underline font-semibold"
                    >App Store</a
                  >
                  or
                  <a
                    href="https://play.google.com/store/apps/details?id=ai.mistral.chat&amp;hl=fr"
                    target="_blank"
                    rel="noopener noreferrer"
                    class="underline font-semibold"
                    >Google Play</a
                  >
                  to try memory on mobile.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  What’s next?
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  We’re continuing to improve how memory works: Trimming noise, speeding up recall,
                  and making it easier to organize long-term. You’ll see updates soon that let you
                  sort memories into categories, instantly forget something, and get clearer
                  visibility into what memory was used and when.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Under the hood, we’ve built a graph-based architecture that balances performance
                  with context-awareness, so memory doesn’t just get longer, it gets smarter. AI is
                  still early. Models will change, and fast. Memories are what keep your assistant
                  anchored in your context, even as everything else shifts. Not a feature. Not a
                  friend. A system you can trust and one that grows with you.
                </p>
