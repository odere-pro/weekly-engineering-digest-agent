              <section class="relative w-full">
                <p class="text-body-large text-text-primary mb-10">
                  Mistral AI continues its mission to deliver the best open models to the developer
                  community. Moving forward in AI requires taking new technological turns beyond
                  reusing well-known architectures and training paradigms. Most importantly, it
                  requires making the community benefit from original models to foster new
                  inventions and usages.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Today, the team is proud to release Mixtral 8x7B, a high-quality sparse mixture of
                  experts model (SMoE) with open weights. Licensed under Apache 2.0. Mixtral
                  outperforms Llama 2 70B on most benchmarks with 6x faster inference. It is the
                  strongest open-weight model with a permissive license and the best model overall
                  regarding cost/performance trade-offs. In particular, it matches or outperforms
                  GPT3.5 on most standard benchmarks.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Mixtral has the following capabilities.
                </p>
                <ul class="mb-10 pl-5 flex flex-col gap-2 list-disc">
                  <li>
                    <p class="text-body-large text-current">
                      It gracefully handles a context of 32k tokens.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      It handles English, French, Italian, German and Spanish.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      It shows strong performance in code generation.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      It can be finetuned into an instruction-following model that achieves a score
                      of 8.3 on MT-Bench.
                    </p>
                  </li>
                </ul>
                <h4 class="text-h5 font-mistral text-current mb-5">
                  Pushing the frontier of open models with sparse architectures
                </h4>
                <p class="text-body-large text-text-primary mb-10">
                  Mixtral is a sparse mixture-of-experts network. It is a decoder-only model where
                  the feedforward block picks from a set of 8 distinct groups of parameters. At
                  every layer, for every token, a router network chooses two of these groups (the
                  “experts”) to process the token and combine their output additively.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  This technique increases the number of parameters of a model while controlling
                  cost and latency, as the model only uses a fraction of the total set of parameters
                  per token. Concretely, Mixtral has 46.7B total parameters but only uses 12.9B
                  parameters per token. It, therefore, processes input and generates output at the
                  same speed and for the same cost as a 12.9B model.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Mixtral is pre-trained on data extracted from the open Web – we train experts and
                  routers simultaneously.
                </p>
                <h4 class="text-h5 font-mistral text-current mb-5">Performance</h4>
                <p class="text-body-large text-text-primary mb-10">
                  We compare Mixtral to the Llama 2 family and the GPT3.5 base model. Mixtral

                <h4 class="text-h5 font-mistral text-current mb-5">Instructed models</h4>
                <p class="text-body-large text-text-primary mb-10">
                  We release Mixtral 8x7B Instruct alongside Mixtral 8x7B. This model has been
                  optimised through supervised fine-tuning and direct preference optimisation (DPO)
                  for careful instruction following. On MT-Bench, it reaches a score of 8.30, making
                  it the best open-source model, with a performance comparable to GPT3.5.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Note: Mixtral can be gracefully prompted to ban some outputs from constructing
                  applications that require a strong level of moderation, as exemplified
                  <a
                    href="https://docs.mistral.ai/platform/guardrailing"
                    class="underline font-semibold"
                    >here</a
                  >. A proper preference tuning can also serve this purpose. Bear in mind that
                  without such a prompt, the model will just follow whatever instructions are given.
                </p>
                <h4 class="text-h5 font-mistral text-current mb-5">
                  Deploy Mixtral with an open-source deployment stack
                </h4>
                <p class="text-body-large text-text-primary mb-10">
                  To enable the community to run Mixtral with a fully open-source stack, we have
                  submitted changes to the vLLM project, which integrates Megablocks CUDA kernels
                  for efficient inference.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Skypilot allows the deployment of vLLM endpoints on any instance in the cloud.
                </p>
