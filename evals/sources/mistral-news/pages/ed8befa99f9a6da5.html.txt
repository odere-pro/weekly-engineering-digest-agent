This enables agents to tackle a wide range of tasks, including mathematical calculations and analysis, data visualization and plotting, and scientific computing.</p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/connectors/image_generation/" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Image generation</a></h3>The image generation connector tool, powered by Black Forest Lab FLUX1.1 [pro] Ultra, enables agents to create images for diverse applications. This feature can be leveraged for various use cases such as generating visual aids for educational content, creating custom graphics for marketing materials, or even producing artistic images.</p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/connectors/document_library/" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Document library</a></h3>Document Library is a built-in connector tool that enables agents to access documents from Mistral Cloud. It powers the integrated RAG functionality, strengthening agents’ knowledge by leveraging the content of user-uploaded documents.</p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/connectors/websearch/" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Web search</a></h3>The Agents API offers web search as a connector, enabling developers to combine Mistral models with diverse, up-to-date information from web search, reputable news, and other sources. This integration facilitates the delivery of up-to-date, informed, evidence-supported responses.<br>Agents with web search capabilities show a significant improvement in performance. In the SimpleQA benchmark, Mistral Large and Mistral Medium with web search achieve scores of 75% and 82.32%, respectively, compared to 23% and 22.08% without web search (see figure below).<h4 class="text-h5 font-mistral text-current mb-5">SimpleQA Accuracy (Higher is better)</h4> </p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/mcp/" target="_blank" rel="noopener noreferrer" class="underline font-semibold">MCP tools</a></h3>The Agents API SDK can also leverage tools built on the Model Context Protocol (MCP)—an open, standardized protocol that enables seamless integration between agents and external systems. MCP tools provide a flexible and extensible interface for agents to access real-world context, including APIs, databases, user data, documents, and other dynamic resources. Check out the <a href="#demo-github" class="underline font-semibold">Github</a>, <a href="#demo-finance" class="underline font-semibold">Financial Analyst</a>, and <a href="#demo-linear" class="underline font-semibold">Linear</a> MCP demos to learn how to use MCP tools with Mistral Agents in action.<br><figure class="mb-10"><img src="https://cms.globalaegis.net/api/legacy-media/file/5a0eb67b-819c-4a3f-9cc0-7dba190d58d2.svg" alt="Mcp Mistral" loading="lazy" decoding="async" class="w-full"></figure></p></li></ul><h2 class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16">Memory and context with stateful conversations.</h2><p class="text-body-large text-text-primary mb-10">The Agents API provides robust conversation management through a flexible and stateful conversation system. Each conversation retains its context, allowing for seamless and coherent interactions over time.</p><ul class="mb-10 pl-5 flex flex-col gap-2 list-disc"><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/agents_basics/#conversations" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Conversation management</a></h3>There are two ways to start a conversation:<br>Each conversation maintains a structured history through conversation entries, ensuring that the context is preserved across interactions.</p></li><li><p class="text-body-large text-current"><ol class="mb-10 pl-5 flex flex-col gap-2 list-decimal"><li><p class="text-body-large text-current">With an Agent: Create a conversation with a specific agent_id to leverage its specialized capabilities.</p></li><li><p class="text-body-large text-current">Direct Access: Start a conversation by directly specifying the model and completion parameters, providing quick access to built-in connectors.</p></li></ol></p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/agents_basics/#continue-a-conversation-working" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Stateful interactions and conversation branching</a></h3>Developers are no longer required to monitor conversion history; they have the ability to view past conversations. They can always continue any conversation or initiate new conversation paths from any point. </p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/agents_basics/#streaming-output-working" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Streaming output</a></h3>The API also supports streaming outputs, both when starting a conversation and continuing a previous one. This feature allows for real-time updates and interactions. </p></li></ul><h2 class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16">Agent orchestration.</h2><p class="text-body-large text-text-primary mb-10">The true power of our Agents API lies in its ability to orchestrate multiple agents to solve complex problems. Through dynamic orchestration, agents can be added or removed from a conversation as needed—each one contributing its unique capabilities to tackle different parts of a problem.</p><p class="text-body-large text-text-primary mb-10"><figure class="mb-10"><img src="https://cms.globalaegis.net/api/legacy-media/file/55ca02be-4dfa-4f0e-ba6a-adc7c54dce4c.svg" alt="Agents" loading="lazy" decoding="async" class="w-full"></figure></p><ul class="mb-10 pl-5 flex flex-col gap-2 list-disc"><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/handoffs/#create-an-agentic-workflow" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Creating an agentic workflow</a></h3>To build a workflow with handoffs, start by creating all necessary agents. You can create as many agents as needed, each with specific tools and models, to form a tailored workflow.</p></li><li><p class="text-body-large text-current"><h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12"><a href="https://docs.mistral.ai/agents/handoffs/" target="_blank" rel="noopener noreferrer" class="underline font-semibold">Agent handoffs</a></h3>Once agents are created, define which agents can hand off tasks to others. For example, a finance agent might delegate tasks to a web search agent or a calculator agent based on the conversation&#39;s needs.<br>Handoffs enable a seamless chain of actions. A single request can trigger tasks across multiple agents, each handling specific parts of the request. This collaborative approach allows for efficient and effective problem-solving, unlocking powerful possibilities for real-world applications.</p></li></ul><h2 class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16">Get started.</h2><p class="text-body-large text-text-primary mb-10">To get started, check out our <a href="https://docs.mistral.ai/agents/introduction" target="_blank" rel="noopener noreferrer" class="underline font-semibold">docs</a>, create your first agent, and start building! </p></section></div></div></div><mistral-section-blog-footer class="block sticky bottom-0 left-0 w-full z-20" data-target="#blogpost"><div class="px-4 py-3 flex items-center justify-center md:justify-between gap-4"><mistral-atom-navigation-scroll-progress class="hidden md:block" data-target="#blogpost"><div class="bg-surface-brand-secondary p-1 pl-2 rounded-lg flex gap-2 items-center border border-border-primary"><span class="relative inline-block w-4">
