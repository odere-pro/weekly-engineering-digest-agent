                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Use cases
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Mistral Small 3.1 is a versatile model designed to handle a wide range of
                  generative AI tasks, including instruction following, conversational assistance,
                  image understanding, and function calling. It provides a solid foundation for both
                  enterprise and consumer-grade AI applications.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Key Features and Capabilities
                </h2>
                <ul class="mb-10 pl-5 flex flex-col gap-2 list-disc">
                  <li>
                    <p class="text-body-large text-current">
                      Lightweight: Mistral Small 3.1 can run on a single RTX 4090 or a Mac with 32GB
                      RAM. This makes it a great fit for on-device use cases.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Fast-response conversational assistance: Ideal for virtual assistants and
                      other applications where quick, accurate responses are essential. 
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Low-latency function calling: Capable of rapid function execution within
                      automated or agentic workflows
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Fine-tuning for specialized domains: Mistral Small 3.1 can be fine-tuned to
                      specialize in specific domains, creating accurate subject matter experts. This
                      is particularly useful in fields like legal advice, medical diagnostics, and
                      technical support.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Foundation for advanced reasoning: We continue to be impressed by how the
                      community builds on top of open Mistral models. Just in the last few weeks, we
                      have seen several excellent reasoning models built on Mistral Small 3, such as
                      the
                      <a
                        href="https://huggingface.co/NousResearch/DeepHermes-3-Mistral-24B-Preview"
                        class="underline font-semibold"
                        >DeepHermes 24B</a
                      >
                      by Nous Research. To that end, we are releasing both base and instruct
                      checkpoints for Mistral Small 3.1 to enable further downstream customization
                      of the model.
                    </p>
                  </li>
                </ul>
                <p class="text-body-large text-text-primary mb-10">
                  Mistral Small 3.1 can be used across various enterprise and consumer applications
                  that require multimodal understanding, such as document verification, diagnostics,
                  on-device image processing, visual inspection for quality checks, object detection
                  in security systems, image-based customer support, and general purpose assistance.
                </p>
