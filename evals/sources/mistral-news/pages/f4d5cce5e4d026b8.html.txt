                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Agentic LLMs for software development
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  While typical LLMs are excellent at atomic coding tasks such as writing standalone
                  functions or code completion, they currently struggle to solve real-world software
                  engineering problems. Real-world development requires contextualising code within
                  a large codebase, identifying relationships between disparate components, and
                  identifying subtle bugs in intricate functions. 
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Devstral is designed to tackle this problem. Devstral is trained to solve real
                  GitHub issues; it runs over code agent scaffolds such as OpenHands or SWE-Agent,
                  which define the interface between the model and the test cases. Here, we show
                  Devstral’s performance on the popular SWE-Bench Verified benchmark, a dataset of
                  500 real-world GitHub issues which have been manually screened for correctness.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Devstral achieves a score of 46.8% on SWE-Bench Verified, outperforming prior
                  open-source SoTA models by more than 6% points. When evaluated under the same test
                  scaffold (OpenHands, provided by
                  <a
                    href="https://www.all-hands.dev/"
                    target="_blank"
                    rel="noopener noreferrer"
                    class="underline font-semibold"
                    >All Hands AI</a
                  >
                  🙌), Devstral exceeds far larger models such as Deepseek-V3-0324 (671B) and Qwen3
                  232B-A22B. 
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  In the table below, we also compare Devstral to closed and open models evaluated
                  under any scaffold (including ones custom for the model). Here, we find that
                  Devstral achieves substantially better performance than a number of closed-source
                  alternatives. For example, Devstral surpasses the recent GPT-4.1-mini by over
                  20%. 
                </p>
                <p class="text-body-large text-text-primary mb-10"> </p>
                <p class="text-body-large text-text-primary mb-10"> </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Versatile: local deployment ↔️ enterprise use ↔️ copilots
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Devstral is light enough to run on a single RTX 4090 or a Mac with 32GB RAM,
                  making it an ideal choice for local deployment and on-device use. Coding platforms

                </p>
                <p class="text-body-large text-text-primary mb-10">

                  stringent security and compliance requirements. 
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Finally, if you’re building or using an agentic coding IDE, plugin, or
