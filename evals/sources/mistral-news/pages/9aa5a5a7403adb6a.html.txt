                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral Embed can output embeddings with different dimensions and precisions,
                  and the figure below illustrates the trade-offs between retrieval quality and
                  storage costs. Codestral Embed with dimension 256 and int8 precision still
                  performs better than any model from our competitors. The dimensions of our
                  embeddings are ordered by relevance. For any integer target dimension n, you can
                  choose to keep the first n dimensions for a smooth trade-off between quality and
                  cost.
                </p>

                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">Results</h3>
                <p class="text-body-large text-text-primary mb-10">
                  Below  we show the performance of Codestral Embed for several categories. The
                  details of the benchmarks corresponding to each category can be found in the table
                  in the “Benchmarks details” section.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  SWE-Bench is based on a dataset of real-world GitHub issues and corresponding
                  fixes, and is especially relevant for retrieval-augmented generation for coding
                  agents. Text2Code (GitHub) contains benchmarks relevant for giving context for
                  code completion or edition. We believe that these two categories are especially
                  relevant to code assistants. 
                </p>

                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Use cases
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral Embed is optimized for high-performance code retrieval and semantic
                  understanding. It enables a range of practical applications across development
                  workflows, especially when working with large-scale code corpora. 
                </p>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  1. Retrieval-augmented generation 
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral Embed facilitates rapid and efficient context retrieval for code
                  completion, editing, or explanation tasks. It is ideal for AI-powered software
                  engineering in copilots or coding agent frameworks. 
                </p>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  2. Semantic code search
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  Embed enables accurate search of relevant code snippets from natural language or
                  code queries. It is suitable for use within developer tools, documentation
                  systems, and copilots. 
                </p>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  3. Similarity search and duplicate detection
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  The model’s embeddings can be used to identify near-duplicate or functionally
                  similar code segments, even with significant lexical variation. This supports use
                  cases such as identifying reusable code to avoid duplicates, or detecting
                  copy-paste reuse to enforce licensing policies.
                </p>
                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  4. Semantic clustering and code analytics
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral Embed supports unsupervised grouping of code based on functionality or
                  structure. This is useful for analyzing repository composition, identifying
                  emergent architecture patterns, or feeding into automated documentation and
                  categorization systems.
                </p>

                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  Chunking parameters
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  For retrieval use cases, while you can use the full context size of 8192 tokens,
                  it is often more efficient to chunk your dataset. We recommend using chunks of
                  3000 characters with 1000 characters overlap. Larger chunks tend to adversely
                  affect the performance of the retrieval system. Refer to
                  <a
