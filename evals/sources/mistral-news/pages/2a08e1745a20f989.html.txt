              <section class="relative w-full">
                <p class="text-body-large text-text-primary mb-10">
                  We introduce Codestral, our first-ever code model. Codestral is an open-weight
                  generative AI model explicitly designed for code generation tasks. It helps
                  developers write and interact with code through a shared instruction and
                  completion API endpoint. As it masters code and English, it can be used to design
                  advanced AI applications for software developers.
                </p>
                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  A model fluent in 80+ programming languages
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral is trained on a diverse dataset of 80+ programming languages, including
                  the most popular ones, such as Python, Java, C, C++, JavaScript, and Bash. It also
                  performs well on more specific ones like Swift and Fortran. This broad language
                  base ensures Codestral can assist developers in various coding environments and
                  projects.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Codestral saves developers time and effort: it can complete coding functions,
                  write tests, and complete any partial code using a fill-in-the-middle mechanism.
                  Interacting with Codestral will help level up the developer&#39;s coding game and
                  reduce the risk of errors and bugs.
                </p>

                  Download and test Codestral.

                <h3 class="text-h4 font-mistral text-current mb-5 not-first:mt-12">
                  Use Codestral via its dedicated endpoint
                </h3>
                <p class="text-body-large text-text-primary mb-10">
                  With this release, comes the addition of a new endpoint:
                  <code
                    class="bg-surface-brand-secondary border border-border-primary rounded-sm px-2 py-px text-text-brand-8 dark:text-text-brand-7 text-base"
                    >codestral.mistral.ai</code
                  >. This endpoint should be preferred by users who use our Instruct or
                  Fill-In-the-Middle routes inside their IDE. The API Key for this endpoint is
                  managed at the personal level and isn&#39;t bound by the usual organization rate
                  limits. We&#39;re allowing use of this endpoint for free during a beta period of 8
                  weeks and are gating it
                  <a href="https://console.mistral.ai/codestral" class="underline font-semibold"
                    >behind a waitlist</a
                  >
                  to ensure a good quality of service. This endpoint should be preferred by
                  developers implementing IDE plugins or applications where customers are expected
                  to bring their own API keys.
                </p>

                  suited for research, batch queries or third-party application development that
