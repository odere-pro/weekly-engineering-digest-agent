                  local deployment options, and enterprise tooling into one fully supported package,
                  so developers can 10X their productivity with the full backing of their IT and
                  security teams. 
                </p>

                <h2
                  class="text-h3 font-mistral text-current mb-5 pb-5 border-b border-border-primary not-first:mt-16"
                >
                  Why we built Mistral Code
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  Our goal with Mistral Code is simple: deliver best-in-class coding models to
                  enterprise developers, enabling everything from instant completions to multi-step
                  refactoring—through an integrated platform deployable in the cloud, on reserved
                  capacity, or air-gapped on-prem GPUs.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Unlike typical SaaS copilots, all parts of the stack—from models to code—are
                  delivered by one provider subject to a single set of SLAs, and every line of code
                  resides inside the customer’s enterprise boundary. 
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  When we spoke with VPs of engineering, platform leads, and CISOs, they surfaced
                  four recurring blockers that stop mainstream copilots at the proof-of-concept
                  stage:
                </p>
                <ol class="mb-10 pl-5 flex flex-col gap-2 list-decimal">
                  <li>
                    <p class="text-body-large text-current">
                      Limited connectivity to proprietary repos and internal services.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Minimal customisation of the underlying models or prompts.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Shallow task coverage that ends at “autocomplete” instead of finishing
                      multi-step work.
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      Fragmented SLAs spread across one vendor for the plug-in, another for the
                      model, and a third for infra.
                    </p>
                  </li>
                </ol>
                <p class="text-body-large text-text-primary mb-10">
                  Mistral Code addresses those pain points with a single, vertically-integrated
                  offering: models, plugin, admin controls, and 24X7 support—so platform teams
                  retain visibility and can tie AI-powered productivity back to ROI.
                </p>

                >
                  Code with intelligence, control with confidence
                </h2>
                <p class="text-body-large text-text-primary mb-10">
                  At its core, Mistral Code is powered by four models that are state of the art in
                  coding: 
                </p>
                <ol class="mb-10 pl-5 flex flex-col gap-2 list-decimal">
                  <li>
                    <p class="text-body-large text-current">
                      <a href="https://mistral.ai/news/codestral" class="underline font-semibold"
                        >Codestral</a
                      >
                      for fill-in-the-middle / code autocomplete 
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      <a
                        href="https://mistral.ai/news/codestral-embed"
                        class="underline font-semibold"
                        >Codestral Embed</a
                      >
                      for code search and retrieval
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      <a href="https://mistral.ai/news/devstral" class="underline font-semibold"
                        >Devstral</a
                      >
                      for agentic coding 
                    </p>
                  </li>
                  <li>
                    <p class="text-body-large text-current">
                      And
                      <a
                        href="https://mistral.ai/news/mistral-medium-3"

                        >Mistral Medium</a
                      >
                      for chat assistance 
                    </p>
                  </li>
                </ol>
                <p class="text-body-large text-text-primary mb-10">
                  Critically, customers can fine-tune or post-train the underlying models on private
                  repositories or distill lightweight variants—capabilities that simply don’t exist
                  in closed copilots tied to proprietary APIs. 
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  Mistral Code is proficient in 80+ programming languages and can reason over files,
                  Git diffs, terminal output, and issues. We’re currently testing the product in
                  helping engineers move beyond coding assistance and suggestions to complete fully
                  scoped tickets: opening files, writing new modules, updating tests, and even
                  executing shell commands—all under configurable approval workflows so senior
                  engineers stay in control.
                </p>
                <p class="text-body-large text-text-primary mb-10">
                  For IT managers, a rich admin console exposes granular platform controls, deep
                  observability, seat management, and usage analytics.
                </p>
