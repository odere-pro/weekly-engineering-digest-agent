              </div>
            </div>
            <h2 id="summary"><a href="#summary">Summary</a></h2>
            <p>
              The OpenSSL project released a security advisory that includes 12 CVEs. After
              assessment, we have concluded that three CVEs affect Node.js (severity Low to
              Moderate). Given the limited attack surface, the OpenSSL updates will be included in
              upcoming regular Node.js releases rather than dedicated security releases.
            </p>
            <h2 id="analysis"><a href="#analysis">Analysis</a></h2>
            <p>
              All three vulnerabilities relate to how Node.js processes PFX (PKCS#12) certificate
              files, which are used when configuring TLS connections via the
              <code>pfx</code> option. An attacker would need to provide a specially crafted PFX
              file to trigger any of these issues. Since PFX files typically come from trusted local
              sources (e.g., your own private keys and certificates), the attack surface is limited
              in practice.
            </p>

            <h2 id="cves-that-do-not-affect-nodejs">
              <a href="#cves-that-do-not-affect-nodejs">CVEs that do not affect Node.js</a>
            </h2>
            <p>The following 9 CVEs do not affect Node.js on any branch:</p>
            <ul>
              <li>
                <strong>CVE-2025-15467 (High, CMS AuthEnvelopedData):</strong> Node.js does not use
                CMS APIs.
              </li>
              <li>
                <strong>CVE-2025-15468 (Low, SSL_CIPHER_find + QUIC):</strong> Node.js never calls
                <code>SSL_CIPHER_find()</code>.
              </li>
              <li>
                <strong>CVE-2025-15469 (Low, openssl dgst truncation):</strong> Command-line tool
                only.
              </li>
              <li>
                <strong>CVE-2025-66199 (Low, TLS 1.3 CompressedCertificate):</strong> Node.js builds
                with <code>OPENSSL_NO_COMP</code> on all branches, so certificate compression is
                disabled.
              </li>
              <li>
                <strong>CVE-2025-68160 (Low, BIO_f_linebuffer):</strong> Node.js does not use this
                BIO filter.
              </li>
              <li>
                <strong>CVE-2025-69418 (Low, low-level OCB):</strong> Node.js uses the EVP API,
                which the advisory confirms avoids the vulnerable path.
              </li>
              <li>
                <strong>CVE-2025-69419 (Low, PKCS12_get_friendlyname):</strong> Node.js does not
                call this function; the advisory notes <code>PKCS12_parse()</code> uses a separate
                safe path.
              </li>
              <li>
                <strong>CVE-2025-69420 (Low, TS_RESP_verify_response):</strong> Node.js does not use
                timestamp protocol APIs.
              </li>
              <li>
                <strong>CVE-2026-22796 (Low, PKCS7_digest_from_attributes):</strong> Node.js does
                not call PKCS#7 signature verification APIs.
              </li>
            </ul>
