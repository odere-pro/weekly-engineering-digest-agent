            <h3 id="notable-changes"><a href="#notable-changes">Notable Changes</a></h3>
            <h4 id="openssl-updated-to-352">
              <a href="#openssl-updated-to-352">OpenSSL updated to 3.5.2</a>
            </h4>
            <p>
              For official Node.js builds, or builds using the default build configuration, Node.js
              now bundles OpenSSL 3.5.2. This update allows Node.js 22.x to be supported through to
              the planned End-of-Life date of 2027-04-30 as the previously bundled OpenSSL 3.0.x
              goes out of support in September 2026.
            </p>
            <p>
              This change does not affect third-party builds of Node.js that link to an external
              OpenSSL (or OpenSSL-compatible) library.
            </p>
