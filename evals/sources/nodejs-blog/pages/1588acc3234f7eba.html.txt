            <h2 id="2025-11-17-version-2521-current-aduh95">
              <a href="#2025-11-17-version-2521-current-aduh95"
                >2025-11-17, Version 25.2.1 (Current), @aduh95</a
              >
            </h2>
            <p>
              This release reverts the spec-compliant behavior of sometimes throwing on
              <code>localStorage</code> access. We received feedback that this change on an
              experimental API was too breaking for a semver-minor release, so we decided to push it
              back for Node.js 26.0.0.
            </p>
