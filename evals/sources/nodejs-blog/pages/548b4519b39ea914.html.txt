                Check out the New Node.js API Documentation Preview
              </div>
            </div>
            <p>
              We&#x27;ve been rebuilding how Node.js generates and presents its API documentation,
              and a preview is now live at
              <a href="https://beta.docs.nodejs.org/">beta.docs.nodejs.org</a>. Before it becomes
              the default, we want as many people as possible to use it for real work and tell us
              what you think.
            </p>
            <h2 id="whats-different-for-readers">
              <a href="#whats-different-for-readers">What&#x27;s different for readers</a>
            </h2>
            <p>
              The content itself hasn&#x27;t changed: every page is generated from the same Markdown
              files in the <a href="https://github.com/nodejs/node">nodejs/node</a> repository that
              power the current docs. The features you rely on today made the trip too: light and
              dark themes, ESM/CJS switching and copy buttons on snippets, stability badges, version
              history, and the Markdown version of every page.
            </p>
            <p>
              The redesign goes deeper than visuals, though: navigation, layout, and readability
              were all reworked so that finding and understanding an API takes less effort. On top
              of that, the beta adds things the current docs have never had:
            </p>
            <ul>
              <li>
                <strong>Search</strong>: For the first time, the API docs have built-in search. A
                search box on every page, with a keyboard shortcut, lets you jump anywhere in the
                API without a detour through a search engine.
              </li>
              <li>
                <strong>One design across the project</strong>: The API docs now share the design
                system of the nodejs.org website, with a persistent sidebar listing every module, an
                always-visible per-page table of contents, and a layout that works on small screens.
              </li>
              <li>
                <strong>llms.txt</strong>: We&#x27;ve already shipped
                <a href="https://nodejs.org/llms.txt">llms.txt</a>, giving AI tools a clean,
                structured entry point to the API reference.
              </li>
            </ul>
            <p>
              And that&#x27;s not the whole list: the beta also ships features like reading times
              and announcement bars.
            </p>
            <p>
              We also care about the needs of every user, and we pay attention to the ones that are
              easy to overlook. Every page stays usable even with JavaScript disabled and offline.
            </p>
            <h2 id="under-the-hood"><a href="#under-the-hood">Under-the-hood</a></h2>
            <p>
              The redesigned documentation is built with
              <a href="https://github.com/nodejs/doc-kit">doc-kit</a>, a standalone tool developed
              by the Node.js Project to replace the previous legacy documentation generator.
            </p>
            <p>
              For more information on doc-kit and its capabilities for other projects, please refer
              to <a href="https://github.com/nodejs/doc-kit">its repository</a>. This will also be
              the place where bug reports, feature requests, and other tasks should be tracked.
            </p>
            <h2 id="we-need-your-feedback">
              <a href="#we-need-your-feedback">We need your feedback</a>
            </h2>
            <p>
              While we are proud to state that the redesigned documentation is entering its final
              stage of development, feedback is still a crucial part of this migration, and
              we&#x27;d love to hear your thoughts on this process. Please open an issue on the
              <a href="https://github.com/nodejs/doc-kit/issues">nodejs/doc-kit</a> repository with
              anything you find, big or small.
            </p>
            <h2 id="acknowledgments"><a href="#acknowledgments">Acknowledgments</a></h2>
            <p>
              None of this would exist without the
              <a href="https://github.com/nodejs/web-team/blob/main/MEMBERS.md">Node.js Web Team</a
              >, whose members designed, built, and reviewed everything described in this post.
              Thanks as well to the Node.js community and the collaborators who have already helped
              by reviewing, testing, and making suggestions along the way. Thank you all for making
              this possible.
            </p>
