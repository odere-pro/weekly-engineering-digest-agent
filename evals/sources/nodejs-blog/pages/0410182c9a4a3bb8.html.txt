            <h3 id="notable-changes"><a href="#notable-changes">Notable Changes</a></h3>
            <h4 id="streamlined-building-process-of-single-executable-applications-sea">
              <a href="#streamlined-building-process-of-single-executable-applications-sea"
                >Streamlined building process of Single Executable Applications (SEA)</a
              >
            </h4>
            <p>
              This release introduces a new <code>--build-sea</code> command-line flag that
              simplifies the process of building
              <a href="https://nodejs.org/api/single-executable-applications.html"
                >Single Executable Applications (SEA)</a
              >
              using Node.js.
            </p>
            <p>
              Previously, SEA generation involved copying the executable, generating the preparation
              blob with <code>--experimental-sea-config</code>, and injecting the blob into the copy
              using <a href="https://github.com/nodejs/postject">nodejs/postject</a>. With the new
              <code>--build-sea</code> flag, these steps are now consolidated into a single step
              available from Node.js core.
            </p>

            <p>
              For the time being, backward compatibility with the postject-based SEA building
              process as well as the <code>--experimental-sea-config</code> will be maintained,
              until there&#x27;s motivation to break it (e.g. for optimizations).
            </p>
            <p>
              See the
              <a
                href="https://nodejs.org/download/release/v25.5.0/docs/api/single-executable-applications.html#generating-single-executable-applications-with---build-sea"
                >documentation</a
              >
              for more details.
            </p>
