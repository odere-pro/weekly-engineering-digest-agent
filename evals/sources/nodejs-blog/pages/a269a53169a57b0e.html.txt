            <ul>
              <li>
                (CVE-2026-56846) http2: retain header memory in session accounting (Matteo Collina)
                – High
              </li>
              <li>
                (CVE-2026-56848) http2: defer rst stream while in scope (Matteo Collina) – High
              </li>
              <li>
                (CVE-2026-58043) permission: avoid granting radix split nodes (RafaelGSS) – High
              </li>
              <li>
                (CVE-2026-56850) https: distinguish PFX object-array agent keys (RafaelGSS) – Medium
              </li>
              <li>
                (CVE-2026-58040) https: bind identity checks to session reuse (Matteo Collina) –
                Medium
              </li>
              <li>
                (CVE-2026-58041) sqlite: invalidate tag store iterators on statement reset (Matteo
                Collina) – Medium
              </li>
              <li>
                (CVE-2026-58042) dns: handle large resolveAny address replies (RafaelGSS) – Medium
              </li>
              <li>
                (CVE-2026-58045) zlib: throw on out-of-bounds write buffers (RafaelGSS) – Medium
              </li>
              <li>
                (CVE-2026-56847) permission: enforce fs write permission for trace events
                (RafaelGSS) – Low
              </li>
              <li>(CVE-2026-58039) permission: check final report output path (RafaelGSS) – Low</li>
              <li>
                (CVE-2026-58044) http: reject requests exceeding max header count (Matteo Collina) –
                Low
              </li>

              <li>deps: update undici to 7.29.0 (Node.js GitHub Bot)</li>
            </ul>
