            <h4 id="test-runner-module-mocking-improvements">
              <a href="#test-runner-module-mocking-improvements"
                >Test runner module mocking improvements</a
              >
            </h4>
            <p>
              <code>MockModuleOptions.defaultExport</code> and
              <code>MockModuleOptions.namedExports</code> have been consolidated into a single
              option <code>MockModuleOptions.exports</code> to align with user expectations and
              other test runners.
            </p>
            <p>
              A <code>default</code> property on <code>MockModuleOptions.exports</code> represents
              the default export, and own enumerable properties are treated as named exports.
            </p>
            <p>
              An automated migration is available to update user code:
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/mock-module-exports"
                >https://github.com/nodejs/userland-migrations/tree/main/recipes/mock-module-exports</a
              >
            </p>
