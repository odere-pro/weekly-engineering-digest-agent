            <h1 id="nodejs-v16-to-v18"><a href="#nodejs-v16-to-v18">Node.js v16 to v18</a></h1>
            <div class="index-module__VYslka__alertBox index-module__VYslka__info">
              <span class="index-module__VYslka__title">!</span
              ><span class="index-module__VYslka__content"
                ><p>
                  This article covers a part of the migration from Node.js v16 to v18. The userland
                  migrations team is working on more codemods to help you with the migration.
                </p></span
              >
            </div>
            <p>
              This page provides a list of codemods to help you migrate your code from Node.js v16
              to v18.
            </p>
            <h2 id="err-invalid-callback">
              <a href="#err-invalid-callback"><code>err-invalid-callback</code></a>
            </h2>
            <p>
              In Node.js v18, the
              <a href="https://nodejs.org/api/deprecations.html#DEP0159">DEP0159</a> deprecation was
              introduced, which deprecated the <code>ERR_INVALID_CALLBACK</code> error code in favor
              of <code>ERR_INVALID_ARG_TYPE</code>. This codemod will help you replace any
              references to the old error code with the new one.
            </p>
            <p>
              The source code for this codemod can be found in the
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/err-invalid-callback"
                >err-invalid-callback directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/err-invalid-callback"
                >Codemod Registry</a
              >.
            </p>
