            <ul>
              <li>(CVE-2025-59465) add TLSSocket default error handler</li>
              <li>(CVE-2025-55132) disable futimes when permission model is enabled</li>
              <li>(CVE-2025-55130) require full read and write to symlink APIs</li>
              <li>(CVE-2025-59466) rethrow stack overflow exceptions in async_hooks</li>
              <li>(CVE-2025-55131) refactor unsafe buffer creation to remove zero-fill toggle</li>
              <li>(CVE-2026-21637) route callback exceptions through error handlers</li>
            </ul>
