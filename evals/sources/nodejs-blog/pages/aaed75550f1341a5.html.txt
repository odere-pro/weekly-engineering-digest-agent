            <h1 id="nodejs-v14-to-v16"><a href="#nodejs-v14-to-v16">Node.js v14 to v16</a></h1>
            <div class="index-module__VYslka__alertBox index-module__VYslka__info">
              <span class="index-module__VYslka__title">!</span
              ><span class="index-module__VYslka__content"
                ><p>
                  This article covers a part of the migration from Node.js v14 to v16. The userland
                  migrations team is working on more codemods to help you with the migration.
                </p></span
              >
            </div>
            <p>
              This page provides a list of codemods to help you migrate your code from Node.js v14
              to v16.
            </p>
            <h2 id="create-require-from-path">
              <a href="#create-require-from-path"><code>create-require-from-path</code></a>
            </h2>
            <p>
              Node.js v16 replaced the
              <a href="https://nodejs.org/api/module.html#module_module_createrequirefrompath"
                ><code>createRequireFromPath</code></a
              >
              function, deprecated in
              <a href="https://nodejs.org/api/deprecations.html#DEP0148">DEP0148</a>, with the
              modern
              <a href="https://nodejs.org/api/module.html#module_module_createrequire"
                ><code>createRequire</code></a
              >
              function. This codemod replaces calls of the deprecated function with the modern
              alternative mentioned.
            </p>
            <p>
              The source code for this codemod can be found in the
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/create-require-from-path"
                >create-require-from-path directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/create-require-from-path"
                >Codemod Registry</a
              >.
            </p>
            <div class="index-module__HWYciG__root">

            <h2 id="process-main-module">
              <a href="#process-main-module"><code>process-main-module</code></a>
            </h2>
            <p>
              The <code>process.mainModule</code> property was deprecated in favor of
              <code>require.main</code>. This codemod will help you replace the old
              <code>process.mainModule</code> usage with the new <code>require.main</code> usage.
            </p>
            <p>
              So the codemod handle
              <a href="https://nodejs.org/api/deprecations.html#DEP0138">DEP0138</a>.
            </p>
            <p>
              The source code for this codemod can be found in the
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/process-main-module"
                >process-main-module directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/process-main-module"
                >Codemod Registry</a
              >.
            </p>
            <div class="index-module__HWYciG__root">

            <h2 id="rmdir">
              <a href="#rmdir"><code>rmdir</code></a>
            </h2>
            <p>
              The <code>fs.rmdir</code> function was deprecated in favor of <code>fs.rm</code> with
              the <code>{ recursive: true }</code> option. This codemod will help you replace the
              old <code>fs.rmdir</code> function with the new <code>fs.rm</code> function.
            </p>
            <p>
              so this codemod handle
              <a href="https://nodejs.org/api/deprecations.html#DEP0147">DEP0147</a>.
            </p>
            <p>
              The source code for this codemod can be found in the
              <a href="https://github.com/nodejs/userland-migrations/tree/main/recipes/rmdir"
                >rmdir directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/rmdir">Codemod Registry</a>.
            </p>

            <h2 id="tmpdir-to-tmpdir">
              <a href="#tmpdir-to-tmpdir"><code>tmpDir-to-tmpdir</code></a>
            </h2>
            <p>
              The <code>tmpDir</code> function was renamed to <code>tmpdir</code> in Node.js v16.
              This codemod will help you replace all instances of <code>tmpDir</code> with
              <code>tmpdir</code>.
            </p>
            <p>
              So the codemod handles
              <a href="https://nodejs.org/docs/latest/api/deprecations.html#dep0022-ostmpdir"
                >DEP0022</a
              >.
            </p>
            <p>
              The source code for this codemod can be found in the
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/tmpdir-to-tmpdir"
                >tmpdir-to-tmpdir directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/tmpDir-to-tmpdir"
                >Codemod Registry</a
              >.
            </p>
