            <h1 id="nodejs-v12-to-v14"><a href="#nodejs-v12-to-v14">Node.js v12 to v14</a></h1>
            <div class="index-module__VYslka__alertBox index-module__VYslka__info">
              <span class="index-module__VYslka__title">!</span
              ><span class="index-module__VYslka__content"
                ><p>
                  This article covers a part of the migration from Node.js v12 to v14. The userland
                  migrations team is working on more codemods to help you with the migration.
                </p></span
              >
            </div>
            <p>
              This page provides a list of codemods to help you migrate your code from Node.js v12
              to v14.
            </p>
            <h2 id="util-print-to-console-log">
              <a href="#util-print-to-console-log"><code>util-print-to-console-log</code></a>
            </h2>
            <p>
              This codemod transforms calls of various now-deprecated <code>node:util</code> log
              functions into the modern alternative, <code>console.log</code> and
              <code>console.error</code>:
            </p>
            <ul>
              <li>
                <a href="https://nodejs.org/api/deprecations.html#DEP0026">DEP0026</a>:
                <code>util.print</code> → <code>console.log</code>
              </li>
              <li>
                <a href="https://nodejs.org/api/deprecations.html#DEP0027">DEP0027</a>:
                <code>util.puts</code> → <code>console.log</code>
              </li>
              <li>
                <a href="https://nodejs.org/api/deprecations.html#DEP0028">DEP0028</a>:
                <code>util.debug</code> → <code>console.error</code>
              </li>
              <li>
                <a href="https://nodejs.org/api/deprecations.html#DEP0029">DEP0029</a>:
                <code>util.error</code> → <code>console.error</code>
              </li>
            </ul>
            <p>
              The source code for this codemod can be found in the
              <a
                href="https://github.com/nodejs/userland-migrations/tree/main/recipes/util-print-to-console-log"
                >util-print-to-console-log directory</a
              >.
            </p>
            <p>
              You can find this codemod in the
              <a href="https://app.codemod.com/registry/@nodejs/util-print-to-console-log"
                >Codemod Registry</a
              >.
            </p>
