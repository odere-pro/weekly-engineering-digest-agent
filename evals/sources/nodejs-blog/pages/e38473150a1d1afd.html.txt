              <a href="#2025-10-28-version-24110-krypton-lts-richardlau"
                >2025-10-28, Version 24.11.0 &#x27;Krypton&#x27; (LTS), @richardlau</a
              >
            </h2>
            <h3 id="notable-changes"><a href="#notable-changes">Notable Changes</a></h3>
            <p>
              This release marks the transition of Node.js 24.x into Long Term Support (LTS) with
              the codename &#x27;Krypton&#x27;. It will continue to receive updates through to the
              end of April 2028.
            </p>
            <p>
              Other than updating metadata, such as the <code>process.release</code> object, to
              reflect that the release is LTS, no further changes from Node.js 24.10.0 are included.
            </p>
            <h3 id="known-issue"><a href="#known-issue">Known issue</a></h3>
            <p>
              An issue has been identified in the Node.js 24.x line with
              <code>Buffer.allocUnsafe</code> unintentionally returning zero-filled buffers. This
              API is
              <a
                href="https://nodejs.org/docs/latest-v24.x/api/buffer.html#static-method-bufferallocunsafesize"
                >documented to return uninitialized memory</a
              >. The documented behavior will be restored in the next Node.js 24.x LTS release to
              bring it back in line with previous releases. For more information, see
              <a href="https://github.com/nodejs/node/issues/60423">#60423</a>.
            </p>
