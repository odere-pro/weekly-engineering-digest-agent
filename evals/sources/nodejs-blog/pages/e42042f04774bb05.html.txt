            <h4 id="type-stripping-is-enabled-by-default">
              <a href="#type-stripping-is-enabled-by-default"
                >Type stripping is enabled by default</a
              >
            </h4>
            <p>
              Node.js will be able to execute TypeScript files without additional configuration:
            </p>
            <div class="index-module__HWYciG__root">
              <pre
                class="index-module__HWYciG__content shiki shiki-themes github-light-default nord language-console no-line-numbers"
                tabindex="0"
              ><code><span class="line"><span style="color:#1F2328;--shiki-dark:#ECEFF4">$</span><span style="color:#1F2328;--shiki-dark:#D8DEE9FF"> echo </span><span style="color:#0A3069;--shiki-dark:#ECEFF4">&#x27;</span><span style="color:#0A3069;--shiki-dark:#A3BE8C">const foo: string = &quot;World&quot;; console.log(`Hello ${foo}!`);</span><span style="color:#0A3069;--shiki-dark:#ECEFF4">&#x27;</span><span style="color:#CF222E;--shiki-dark:#81A1C1"> &gt;</span><span style="color:#1F2328;--shiki-dark:#D8DEE9FF"> file.ts</span></span>
<span class="line"><span style="color:#1F2328;--shiki-dark:#ECEFF4">$</span><span style="color:#1F2328;--shiki-dark:#D8DEE9FF"> node file.ts</span></span>
<span class="line"><span style="color:#0550AE;--shiki-dark:#D8DEE9FF">Hello World!</span></span></code></pre>
              <div class="index-module__HWYciG__footer">
                <span class="index-module__HWYciG__language">Shell Session</span
                ><button
                  class="index-module__EPgSia__button index-module__EPgSia__neutral index-module__HWYciG__action"
                  type="button"
                >
                  Copy to clipboard
                </button>
              </div>
            </div>
            <p>
              There are some limitations in the supported syntax documented at
              <a href="https://nodejs.org/api/typescript.html#type-stripping"
                >https://nodejs.org/api/typescript.html#type-stripping</a
              >.
            </p>
            <p>
              This feature is experimental and is subject to change. Disable it by passing
              <code>--no-experimental-strip-types</code> CLI flag.
            </p>
            <p>
              Contributed by Marco Ippolito in
              <a href="https://github.com/nodejs/node/pull/56350">#56350</a>.
            </p>
