Because only 2B parameters are active per token, each reasoning token is cheap, so you can run agents continuously on your own hardware.</p>

<li><strong>Best-in-class agent:</strong> Competitive with Qwen3.6-35B-A3B, a model with ~50% more total and active parameters, on agentic and tool-use tasks, scoring 48.09 on LiveClaw versus 38.19.  </li>

<h2 class="relative group flex items-baseline">
	<a id="how-we-built-a-reasoning-agent-with-2b-active-parameters" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#how-we-built-a-reasoning-agent-with-2b-active-parameters" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		How we built a reasoning agent with 2B active parameters
	</span>
</h2>
<p>LFM2.5-24B-A2B builds on <a href="https://huggingface.co/LiquidAI/LFM2-24B-A2B">LFM2-24B-A2B</a> and keeps its architecture: 40 layers, 64 experts per MoE block with top-4 routing, and the same hybrid of gated short convolutions and GQA. The context window grows from 32K to 131K tokens, and an <a href="https://www.liquid.ai/blog/tokenizer-expansion" rel="nofollow">in-place tokenizer expansion</a> doubles the vocabulary from 65K to 128K tokens for better non-Latin tokenization. Unlike its predecessor, it is a reasoning-only model that produces an explicit chain of thought before its final answer.</p>
<p>Pre-training was scaled up from ~17T to ~33T tokens. Mid-training then adds 2T tokens at 32K context, weighted toward reasoning, math, code, instruction following, and multilingual text, and 300B tokens at 131K context, weighted toward long-context data. Tool calls and multi-turn trajectories appear throughout both phases. Post-training turns the base model into an agent in five stages:</p>
<ol>
<li><strong>Supervised fine-tuning (SFT)</strong>  </li>
<li><strong>Teacher specialization</strong>  </li>
<li><strong>Multi-domain on-policy distillation (MOPD), non-agentic:</strong> distill the specialist teachers on non-agentic tasks.  </li>
<li><strong>MOPD, agentic:</strong> a second distillation stage focused on agentic tasks.  </li>
<li><strong>Agentic reinforcement learning (Agentic RL):</strong> train the model inside agent harnesses, such as <a href="https://openclaw.ai" rel="nofollow">OpenClaw</a>, <a href="https://hermes-agent.nousresearch.com" rel="nofollow">Hermes Agent</a>, <a href="https://pi.dev" rel="nofollow">Pi</a>, and <a href="https://opencode.ai" rel="nofollow">OpenCode</a>.</li>
</ol>

It is the smallest model in the group, yet it is competitive with MoEs with ~50% more total and active parameters.</p>

<p>For your app, the strengths are tool use and instruction following. LFM2.5-24B-A2B leads or matches the competition on five of the eight tool-use and agentic benchmarks (AutomationBench, BFCLv4, ToolSandbox, LiveClaw, and τ³-Bench Banking), and on AutomationBench it scores more than three times the next-best model. It also leads on all three instruction-following benchmarks. Larger models keep an edge on knowledge-heavy benchmarks like GPQA Diamond, HLE, and AA-Omniscience, and on coding benchmarks like SWE-Bench Verified (OpenCode) and SciCode, so pair LFM2.5-24B-A2B with retrieval or web search for knowledge-heavy workloads.</p>
<p>These results make LFM2.5-24B-A2B a strong foundation for agents that need to reason, call tools, and run reliably on your device.</p>
<h2 class="relative group flex items-baseline">
	<a id="inference-speed-on-cpu-and-gpu" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#inference-speed-on-cpu-and-gpu" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		Inference speed on CPU and GPU
	</span>
</h2>
<p>LFM2.5-24B-A2B ships with day-one support across the inference ecosystem, including llama.cpp, MLX, vLLM, SGLang, and ONNX.</p>
<p><strong>Edge inference.</strong> LFM2.5-24B-A2B is the fastest of the compared MoEs, decoding 184 tokens/s on an M5 Max and 114 tokens/s on a Ryzen AI Max+ 395. That is up to 1.7x faster than the next-best model, while using the least memory.</p>
<p><a href="https://huggingface.co/LiquidAI/LFM2.5-24B-A2B/resolve/main/figures/LFM2.5-24B-A2B-edge-inference.png" rel="nofollow"><img src="https://huggingface.co/LiquidAI/LFM2.5-24B-A2B/resolve/main/figures/LFM2.5-24B-A2B-edge-inference.png" alt="LFM2.5-24B-A2B-edge-inference"></a></p>
<p><strong>GPU inference.</strong> LFM2.5-24B-A2B is the fastest model in its size class, reaching over 21K output tokens per second at high concurrency on a single B300.</p>
<p><a href="https://huggingface.co/LiquidAI/LFM2.5-24B-A2B/resolve/main/figures/LFM2.5-24B-A2B-gpu-inference.png" rel="nofollow"><img src="https://huggingface.co/LiquidAI/LFM2.5-24B-A2B/resolve/main/figures/LFM2.5-24B-A2B-gpu-inference.png" alt="LFM2.5-24B-A2B-gpu-inference"></a></p>
<h2 class="relative group flex items-baseline">
	<a id="how-to-use-lfm25-24b-a2b" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#how-to-use-lfm25-24b-a2b" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		How to use LFM2.5-24B-A2B
	</span>
</h2>
<p>Reach for LFM2.5-24B-A2B when you need agents that reason, call tools, and run reliably on your device.</p>
<p>Install the latest version of <code>transformers</code> (compatible with <code>transformers&gt;=5.0.0</code>):</p>
<pre><code class="language-sh">pip install -U transformers
</code></pre>
<p>Then load and run the model:</p>
<pre><code class="language-py"><span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> AutoModelForCausalLM, AutoTokenizer, TextStreamer

model_id = <span class="hljs-string">"LiquidAI/LFM2.5-24B-A2B"</span>
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map=<span class="hljs-string">"auto"</span>,
    dtype=<span class="hljs-string">"bfloat16"</span>,
<span class="hljs-comment">#   attn_implementation="flash_attention_2" &lt;- uncomment on compatible GPU</span>
)
tokenizer = AutoTokenizer.from_pretrained(model_id)
streamer = TextStreamer(tokenizer, skip_prompt=<span class="hljs-literal">True</span>, skip_special_tokens=<span class="hljs-literal">True</span>)

prompt = <span class="hljs-string">"What is C. elegans?"</span>

input_ids = tokenizer.apply_chat_template(
    [{<span class="hljs-string">"role"</span>: <span class="hljs-string">"user"</span>, <span class="hljs-string">"content"</span>: prompt}],
    add_generation_prompt=<span class="hljs-literal">True</span>,
    return_tensors=<span class="hljs-string">"pt"</span>,
    tokenize=<span class="hljs-literal">True</span>,
)[<span class="hljs-string">"input_ids"</span>].to(model.device)

output = model.generate(
    input_ids,
    do_sample=<span class="hljs-literal">True</span>,
    temperature=<span class="hljs-number">0.1</span>,
    top_k=<span class="hljs-number">50</span>,
    repetition_penalty=<span class="hljs-number">1.05</span>,
    max_new_tokens=<span class="hljs-number">512</span>,
    streamer=streamer,
)
</code></pre>
<h3 class="relative group flex items-baseline">
	<a id="use-it-in-your-agent-harness" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#use-it-in-your-agent-harness" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		Use it in your agent harness
	</span>
</h3>
<p>Serve LFM2.5-24B-A2B locally behind any OpenAI-compatible backend, then point your agent harness at it. For example, with Hermes Agent:</p>
<pre><code class="language-sh">hermes config <span class="hljs-built_in">set</span> model.provider custom
hermes config <span class="hljs-built_in">set</span> model.base_url http://localhost:8080/v1
hermes config <span class="hljs-built_in">set</span> model.default LFM2.5-24B-A2B
hermes config <span class="hljs-built_in">set</span> model.context_length 131072
hermes config <span class="hljs-built_in">set</span> model.api_mode chat_completions
hermes config <span class="hljs-built_in">set</span> agent.tool_use_enforcement <span class="hljs-literal">true</span>
</code></pre>
<p>The port depends on your serving backend: llama.cpp and MLX use <code>8080</code>, vLLM uses <code>8000</code>, SGLang uses <code>30000</code>, and LM Studio uses <code>1234</code>. See the <a href="https://huggingface.co/LiquidAI/LFM2.5-24B-A2B">model card</a> for OpenClaw and Pi configs, and <a href="https://docs.liquid.ai/examples/agent-harnesses" rel="nofollow">our guide</a> for the full setup. Check out our <a href="https://www.liquid.ai/blog/lfm2-5-24b-a2b" rel="nofollow">release blog</a> for video examples.</p>
