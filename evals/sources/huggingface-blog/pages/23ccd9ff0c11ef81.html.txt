<p>We're thrilled to share that <strong>Baseten</strong> is now a supported Inference Provider on the Hugging Face Hub!</p>
<p>Baseten joins our growing ecosystem, enhancing the breadth and capabilities of serverless inference directly on the Hub's model pages. Inference Providers are also seamlessly integrated into our client SDKs (for both JS and Python), making it super easy to use a wide variety of models with your preferred providers.</p>
<p><a href="https://baseten.com" rel="nofollow">Baseten</a> is an AI infrastructure platform that covers serverless AI, training and more. With a catalog of many frontier models, Baseten makes it easy for developers to integrate a wide range of AI capabilities into their applications with minimal setup.</p>
<p>Baseten supports a broad spectrum of model types - from LLMs to text-to-speech and more. As part of this initial integration, Baseten is launching support for <strong>conversational and text-generation tasks</strong> on Hugging Face, enabling access to popular open-weight LLMs such as <a href="https://huggingface.co/moonshotai/Kimi-K3?inference_provider=baseten">Kimi K3</a>, latest <a href="https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731?inference_provider=baseten">DeepSeek V4 Flash</a>, <a href="https://huggingface.co/zai-org/GLM-5.2?inference_provider=baseten">GLM-5.2</a>, and many more. <strong>Support for additional tasks</strong> will roll out soon!</p>
<p>See the full list of models supported by Baseten <a href="https://huggingface.co/models?inference_provider=baseten&amp;sort=trending">here</a>.</p>
<p>Follow Baseten on Hugging Face: <a href="https://huggingface.co/baseten">https://huggingface.co/baseten</a>.</p>

	<a id="how-it-works" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#how-it-works" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		How it works
	</span>
</h2>
<h3 class="relative group flex items-baseline">
	<a id="in-the-website-ui" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#in-the-website-ui" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		In the website UI
	</span>
</h3>
<ol>
<li>In your user account settings, you are able to:</li>
</ol>
<ul>
<li>Set your own API keys for the providers you've signed up with. If no custom key is set, your requests will be routed through HF.</li>
<li>Order providers by preference. This applies to the widget and code snippets in the model pages.</li>
</ul>
<img src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/inference-providers-baseten.png" alt="Inference Providers">

<ol start="2">
<li>As mentioned, there are two modes when calling Inference Providers:</li>
</ol>
<ul>
<li>Custom key (calls go directly to the inference provider, using your own API key of the corresponding inference provider)</li>
<li>Routed by HF (in that case, you don't need a token from the provider, and the charges are applied directly to your HF account rather than the provider's account)</li>
</ul>
<img src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/explainer.png" alt="Inference Providers">

<ol start="3">
<li>Model pages showcase third-party inference providers (the ones that are compatible with the current model, sorted by user preference)</li>
</ol>
<img src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/model-widget-v3.png" alt="Inference Providers">

<h3 class="relative group flex items-baseline">
	<a id="from-the-client-sdks" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#from-the-client-sdks" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		From the client SDKs
	</span>
</h3>
<p>Baseten is available through the Hugging Face SDKs - <code>huggingface_hub</code> (&gt;= 1.26.1) for Python and <code>@huggingface/inference</code> for JavaScript.</p>
<p>The following examples show how to use the latest <a href="/blog/deepseek-ai/DeepSeek-V4-Flash-0731">DeepSeek V4 Flash</a> through Baseten. Use a <a href="https://huggingface.co/settings/tokens">Hugging Face token</a> to authenticate - the request will be routed to Baseten automatically.</p>

Browse the full list of integrations <a href="https://huggingface.co/docs/inference-providers/en/integrations/index">here</a>.</p>

<h2 class="relative group flex items-baseline">
	<a id="billing" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#billing" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		Billing
	</span>
</h2>
<p>For direct requests, i.e. when you use the key from an inference provider, you are billed by the corresponding provider. For instance, if you use a baseten API key you're billed on your baseten account.</p>
<p>For routed requests, i.e. when you authenticate via the Hugging Face Hub, you'll only pay the standard provider API rates. There's no additional markup from us; we just pass through the provider costs directly. (In the future, we may establish revenue-sharing agreements with our provider partners.)</p>
<p><strong>Important Note</strong> ‼️ PRO users get $2 worth of Inference credits every month. You can use them across providers. 🔥</p>

<p>We also provide free inference with a small quota for our signed-in free users, but please upgrade to PRO if you can!</p>
