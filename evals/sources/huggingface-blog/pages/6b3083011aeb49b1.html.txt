<p><!--[--><!--[0--><div class="absolute -left-12 bottom-0 top-0 z-30 not-prose hidden lg:block"><div class="sticky top-4 flex"><div class="h-7 pt-[0.175rem]"><span class="peer" tabindex="0"><button class="select-none text-gray-400 hover:cursor-pointer hover:text-gray-800 dark:text-gray-500 dark:hover:text-gray-400"> <!----></button></span> <div class="invisible w-0 -translate-x-8 -translate-y-6 overflow-hidden rounded-xl border bg-white transition-transform hover:visible hover:w-52 hover:translate-x-0 peer-focus-within:visible peer-focus-within:w-52 peer-focus-within:translate-x-0"> </div></div></div></div><!--]--><!--]-->We are super excited to welcome Jun as our newest team member 🔥. We are completely invested in local AI, and MLX is a central piece of the ecosystem. We are delighted that Jun chose us to set up home and continue contributing to MLX.</p>
<p>MLX is Apple's framework for local AI, especially optimized for Apple Silicon. We are big MLX supporters since it was the Christmas present from <a href="https://x.com/awnihannun/status/1732184443451019431?s=20" rel="nofollow">Awni</a> and <a href="https://x.com/angeloskath/status/1732304844403429477?s=20" rel="nofollow">Angelos</a> in 2023, and proud that Hugging Face is the Hub where people find MLX models and contribute their own. Usage of open, local AI is accelerating, and we believe in a healthy ecosystem where people can find the tools that work for them.</p>
<h2 class="relative group flex items-baseline">
	<a id="what-is-the-impact-for-omlx" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#what-is-the-impact-for-omlx" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		What is the impact for oMLX?
	</span>
</h2>
<p>Stability, and hopefully faster development! Graduating from a side job to a fully maintained and funded project will allow Jun to better guide the contributors and build for the long-term. <a href="https://github.com/jundot/omlx" rel="nofollow">oMLX</a> stays Apache 2.0, and Jun keeps leading it as before.</p>
<h2 class="relative group flex items-baseline">
	<a id="what-is-the-impact-for-mlx-at-large" class="block pr-1.5 text-lg md:absolute md:p-1.5 md:opacity-0 md:group-hover:opacity-100 md:right-full" href="#what-is-the-impact-for-mlx-at-large" rel="nofollow">
		<span class="header-link"> </span>
	</a>
	<span>
		What is the impact for MLX at large?
	</span>
</h2>
<p>Our end goal is to unblock the community to run local AI in any shape or form, and provide the tools and building blocks to make that happen. We expect oMLX to serve as a testbed for new ideas, while leveraging the foundational work of the dependencies it already relies upon, such as <a href="https://github.com/ml-explore/mlx-lm" rel="nofollow">mlx-lm</a> or <a href="https://github.com/Blaizzy/mlx-vlm" rel="nofollow">mlx-vlm</a>. We believe that strong modeling and inference libraries help the community, so we'd love to upstream work to wherever it makes sense. We have been collaborating with many projects mlx-lm, mlx-vlm, LMStudio, and we hope we can strengthen the relationship with <a href="https://x.com/zcbenz" rel="nofollow">Cheng</a>, <a href="https://x.com/Prince_Canuma" rel="nofollow">Prince</a>, <a href="https://x.com/yagilb" rel="nofollow">Yagil</a>, and their teams to better serve the community together.</p>
<p>Concretely, one focus area is the quick transition from a transformers model definition to a reference MLX implementation that can be consumed by different engines, so each one can focus on the unique features they provide. The transformers library has become the reference for ML model definitions, we want to streamline the process to make new transformers models run on MLX.</p>
<p>We are incredibly excited about the future.</p>
<p>Welcome, Jun! 🙌</p>
