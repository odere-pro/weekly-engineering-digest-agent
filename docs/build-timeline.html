What the history says about the method

Contracts first paid off. Freezing the ports, schemas and stubs in the first 15 minutes let 17 modules land in the next 75 minutes, and all 24 by 21:58, with no merge conflicts, because no two workers owned the same file.

Recording data early paid off. The six recorded weeks were frozen at 17:10 on day one. Labeling them was the slowest human step, so it ran while the rest was built.

First diagnoses were often wrong. The W39 format failure had two wrong explanations and one wrong fix (a writer retry) before a replay found a regex bug in the link check. The real cause was in a check, not in a model.

Measuring before fixing caught the wrong guesses that came after it became the rule. The one fix made without a replay, the writer retry, shipped and did not help. From wave 6 on, each issue measured on the real models before changing anything, and that turned three planned fixes into no change, a different change, or a better one.

The bottleneck was a person, not the code. Commit signing waited 7 hours overnight for a 1Password click. The agents kept working by staging commits and using the GPU for the threshold capture and the first eval. It waited again for at least 1h 52m on the 17 Oct afternoon and about 40 minutes before the wave 10 commits.

Waves 8 and 9 reused the method. Wave 8 began with one contracts commit, then seven issue commits built the action-sorted digest and the fetch, show and preview commands. Wave 9 replaced two planned docs issues with one commit that cut the docs from about 4,700 to 1,084 lines.

The restructure came late, and the docs were cut and then asked to grow. Wave 10 moved 265 files into feature folders almost 55 hours in, after 123 commits had been written against the old layout. It was safe because the same 4,161 tests passed, but the layout could have been chosen on day one. The docs went the other way: they were cut to 1,084 lines at 20:27, and the wave 10 plan, written the same evening, asks for a docs wiki, one runbook per task and one page per eval set.
