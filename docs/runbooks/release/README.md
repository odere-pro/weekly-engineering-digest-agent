# Release

Part of [Runbooks](../README.md).

Mark a version of the tool. The package is not published anywhere, so a release is a signed
commit and a signed tag that the maintainer pushes.

| Runbook                           | Use it to                                                                      |
| --------------------------------- | ------------------------------------------------------------------------------ |
| [Cut a release](cut-a-release.md) | Run the CI gates, update the changelog and version, then sign and push the tag |
