# Recover runbooks

Part of [Runbooks](../README.md).

Get a week back to `sent` after something went wrong. Diagnose first with the
[debug runbooks](../debug/README.md), then pick one of these.

| Runbook                                                 | Use it to                                                         |
| ------------------------------------------------------- | ----------------------------------------------------------------- |
| [Resume a partial delivery](resume-partial-delivery.md) | Send the saved digest to the channels that missed it, no models   |
| [Re-run a week](re-run-a-week.md)                       | Run the current week again and send a new digest to every channel |
